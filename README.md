# Simple Brute Force Login Simulator

A small educational Python project that simulates a brute force login attack
using a password wordlist. This project is designed for learning purposes only
and demonstrates how brute force attacks work and how they can be mitigated.

## Features
- Simulates a brute force password attack
- Uses a wordlist to try multiple passwords
- Includes basic rate limiting (account lock simulation)
- Clear console output

## Requirements
- Python 3.x
